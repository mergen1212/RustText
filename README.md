# RustText

Текстовый редактор и просмотрщик больших логов для Windows x64 на Rust и GPUI Kit.

## Запуск

Для переносимой сборки распакуйте архив и запустите `rusttext.exe`. Отладочная и релизная сборки запускаются без отдельного окна консоли. Повторный запуск передаёт файлы открытому RustText. Сборка проверена на Windows 11 x64. Для Windows 10 x64 нужна отдельная проверка.

### Сборка из исходников

Нужны Rust с целью `x86_64-pc-windows-msvc`, инструменты C++ и Windows SDK из Visual Studio, а также CMake в `PATH`. Локальная сборка проверена с Rust 1.100.0 и CMake 4.5.0.

```powershell
cargo run --locked
cargo run --locked -- "C:\путь\к\файлу.txt"
```

- Верхнее меню содержит «Файл», «Инструменты» и «Поиск». Открытие и сохранение собраны в меню «Файл»; отдельной панели этих команд нет.
- Кнопка «+», двойной щелчок по свободному месту на полосе вкладок или `Ctrl+N` создают вкладку «Без имени». «Файл → Открыть…» или `Ctrl+O` открывает файлы. Файлы также можно передать аргументами запуска или перетащить в окно.
- «Файл → Сохранить» (`Ctrl+S`) сохраняет документ, «Файл → Сохранить как…» (`Ctrl+Shift+S`) открывает диалог выбора пути. Для логов эти команды недоступны.
- Двойной щелчок по вкладке или `Ctrl+W` закрывает её. `Ctrl+Shift+T` или кнопка «↶» восстанавливают последнюю закрытую вкладку с её позицией и выделением в редакторе либо позицией и настройками просмотра лога. В меню «Файл → Закрытые вкладки» можно выбрать любую из последних 100 закрытых вкладок. История и текст вкладок «Без имени» сохраняются между запусками.
- `Ctrl+G` или нажатие на номер строки внизу открывает переход к строке.
- «Файл → Недавние файлы» показывает 16 последних открытых или сохранённых файлов. История сохраняется между запусками в `%LOCALAPPDATA%\RustText\recent-files.json`.
- Редактор открывает UTF-8 и UTF-16 с BOM автоматически. «Файл → Открыть в Windows-1251…» явно выбирает Windows-1251. Повторное открытие в другой кодировке перечитывает файл, если во вкладке нет несохранённых изменений.
- Чтобы открывать файлы двойным щелчком, выберите «Файл → Настроить открытие файлов в Windows…». В параметрах Windows назначьте RustText приложением по умолчанию для выбранных расширений .log, .txt, .json и .xml. Если переместите переносимый RustText, выполните настройку ещё раз.
- Правый щелчок по вкладке открытого файла позволяет показать его в Проводнике, скопировать путь или закрыть вкладку.
- Ширина дорожки прокрутки в редакторе и в логах составляет 16 пикселей.

### Регистрация типов файлов для установки

Распакуйте RustText в постоянную папку и запустите команду из этой папки от имени пользователя, который будет работать с программой. хм


```powershell
$registration = Start-Process -FilePath (Resolve-Path '.\rusttext.exe').Path -ArgumentList '--register-file-associations' -Wait -PassThru
if ($registration.ExitCode -ne 0) { throw 'Не удалось зарегистрировать RustText в Windows' }
```

Команда добавляет RustText в список приложений для .txt, .json, .xml и .log. На обычном компьютере назначение подтверждается в «Параметры → Приложения → Приложения по умолчанию». Команда «Файл → Настроить открытие файлов в Windows…» открывает эту страницу.

Для управляемых компьютеров используйте XML в [политике ассоциаций Windows](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-applicationdefaults). Сначала зарегистрируйте RustText в каждом профиле, к которому применяется политика. В XML укажите следующие типы.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<DefaultAssociations>
  <Association Identifier=".txt" ProgId="RustText.Text" ApplicationName="RustText" />
  <Association Identifier=".json" ProgId="RustText.Json" ApplicationName="RustText" />
  <Association Identifier=".xml" ProgId="RustText.Xml" ApplicationName="RustText" />
  <Association Identifier=".log" ProgId="RustText.Log" ApplicationName="RustText" />
</DefaultAssociations>
```

## Сессия, поиск и JSON

- RustText восстанавливает открытые вкладки, черновики, выделение, прокрутку и размер окна. Снимки и две последние завершённые записи журнала находятся в `%LOCALAPPDATA%\RustText\session`. При закрытии окна редактор дожидается записи.
- «Поиск» или `Ctrl+F` открывает нижнюю панель поиска. «Найти» или `Enter` показывает первые 100 совпадений и общее количество. Если истёк лимит времени, панель показывает, сколько совпадений успела найти. Нажатие на результат переводит к совпадению. Оно ненадолго подсвечивается, затем остаётся обведено. `F3` и `Shift+F3` переходят между совпадениями. Если переход по `F3` приостановлен по лимиту времени, нажмите `F3` ещё раз.
- Кнопка «Замена» или `Ctrl+H` показывает поле замены. Поиск может охватывать все текстовые вкладки, замена применяется к текущей. В «Заменить все» нет ограничения по количеству совпадений. На операцию отводится до 400 мс. В регулярном выражении доступны подстановки групп, например `$1`.
- При открытии файла .json и после правок RustText проверяет синтаксис. При ошибке красное предупреждение показывает строку и столбец. «Перейти к ошибке» ставит курсор на нужное место.
- «Инструменты → Форматировать JSON» (`Ctrl+Shift+J`) форматирует выделенный JSON или весь документ. Входной и форматированный JSON ограничены 64 МиБ каждый. `Ctrl+Z` отменяет форматирование. В меню «Инструменты» также находятся замена, переход к строке, перенос строк и масштаб текста.

## Генератор строк

Откройте «Инструменты → Генератор строк…», введите шаблон и количество строк. Результат откроется в новой вкладке, где его можно отредактировать, скопировать или сохранить.

- `{int_from_5}` подставляет 5 в первую строку, 6 во вторую и так далее. Можно выбрать другое начальное число, включая отрицательное.
- `{guid}` создаёт GUID v4 при каждой подстановке.
- `{rand_string}` создаёт строку из 12 латинских букв и цифр. Формат `{rand_string_24}` задаёт свою длину.

Например, шаблон `strokna {int_from_5} {guid} {rand_string_8}` использует три правила в каждой строке. За один запуск можно создать до 1 000 000 строк общим размером до 8 МиБ.

## Большие логи

- Файлы размером больше 50 МиБ автоматически открываются для просмотра. Для меньших используйте «Файл → Открыть как лог…». Там же можно открыть лог в Windows-1251.
- Колёсико прокручивает лог и подгружает соседние строки у границы загруженной области. Ползунок показывает положение по всему доступному участку файла. Его можно перетащить или щёлкнуть по дорожке для перехода к нужной части лога. Длинные строки переносятся по ширине окна. Перенос можно отключить в меню «Инструменты → Перенос строк».
- «Начало», «Назад», «Дальше», «Конец» и поле «Перейти, %» перемещают область просмотра. В логе работают `Ctrl+Home`, `Ctrl+End`, `Page Up`, `Page Down` и копирование выделенного текста через `Ctrl+C`.
- Слева от текста отображаются номера строк исходного файла. Строка состояния показывает диапазон загруженных строк и итоговое количество после индексации. При переходе далеко вперёд номера появляются, когда индекс доходит до выбранной позиции.
- Нижняя панель «Поиск в логе» ищет по строкам и выдаёт результаты порциями. Доступны регулярные выражения, поиск с учётом регистра и целого слова. Результаты показывают номер строки, когда он известен. При переходе совпадение ненадолго подсвечивается, затем остаётся обведено. Если строка превышает предельный размер, поиск сообщает об этом. Если файл обрывается посреди символа UTF‑8, после дописывания кнопка «Ещё» проверяет эту строку заново.
- Для лога, упорядоченного по времени, введите дату и время в поле поиска, например 2026-11-17 01:30:20.0850, и нажмите «Ко времени». RustText откроет первую запись с указанным или более поздним временем. Если ввести только время, например 01:33:42.8750, используется дата просматриваемой записи. «Найти» выполняет обычный текстовый поиск.
- Имя файла, режим просмотра, «Пауза»/«Продолжить», «Следовать за концом» и состояние автообновления находятся в одной строке под вкладками. Пауза останавливает чтение новых данных; следование независимо перемещает видимую область при дописывании. Навигация по файлу находится снизу. При ротации или очистке файла RustText сообщает об изменении и сбрасывает старую границу и индекс.
- В меню «Инструменты» доступны обновление содержимого лога, управление индексированием и операции с началом лога. «Скрыть начало» ограничивает просмотр и поиск. «Удалить начало…» меняет исходный файл после подтверждения. Перед подтверждением RustText подсчитывает удаляемые строки. Для записи нужен эксклюзивный доступ и свободное место под полную резервную копию рядом с исходником. RustText выводит путь к копии после обрезки.
- Сессия восстанавливает вкладку, позицию, скрытую границу и переключатели. Если прежнее содержимое по закладке не удаётся подтвердить, лог открывается с начала. Для лога в сессию записываются только метаданные.

## Обновления

При запуске RustText проверяет новые стабильные [выпуски на GitHub](https://github.com/Illson/RustText/releases) в фоне. Если новая версия доступна, приложение скачивает архив и сверяет его с SHA-256.

Когда обновление готово, «Перезапустить» сохраняет сессию, устанавливает обновление и снова открывает окно. «Позже» скрывает уведомление до следующего запуска.

## Подготовка архива

Выполните команды из корня репозитория в PowerShell.

```powershell
$env:CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_RUSTFLAGS = '-C target-feature=+crt-static'
cargo build --release --locked --target x86_64-pc-windows-msvc
.\tools\Package-RustText.ps1 -ExecutablePath 'target\x86_64-pc-windows-msvc\release\rusttext.exe' -OutputDirectory 'target\distribution\v0.1.1'
```

Для стабильного релиза с тегом вида `v0.1.1` прикрепите к выпуску `RustText.zip` и `RustText.zip.sha256`. По этим именам RustText находит файлы обновления. Замеры первого выпуска приведены в [отчёте](docs/verification.md).

## Проверка

Модульные тесты лежат в `tests/unit/`. Имя файла соответствует модулю, например `session.rs`, `search.rs` или `json_format.rs`. Команда `cargo test --locked session::` запускает тесты журнала сессии.

```powershell
cargo fmt --all -- --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
```
